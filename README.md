# neueface releases

Downloads and the update feed for [neueface](https://neueface.com), the infinite canvas for your
React app, on macOS (Apple Silicon, macOS 13+).

- **Download**: [neueface.com/download](https://neueface.com/download) gives you the newest version
  your license covers. Every version is also under [Releases](https://github.com/Neueface/releases/releases).
- **Updates**: the app updates itself (Sparkle); each release carries its signed `appcast.xml`.

This repository holds release files only. neueface needs a license: [neueface.com](https://neueface.com).
